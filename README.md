# Shopping List Homework

## Description
For this homework, students will create a simple shopping list program using Python lists. The program will allow users to add items to their shopping list, remove items, and see the items currently in their list.

## Learning Outcomes
- Create a list in Python.
- Use `.append()` to add items to a list.
- Use `.remove()` to remove items from a list.
- Print a list to display its contents.

## Homework Tasks
1. Create an empty list to store shopping items.
2. Ask the user to enter items and use `.append()` to add them to the list.
3. Allow the user to remove an item using `.remove()`.
4. Print the final list so the user can see all the items they added.
