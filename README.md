## Homework

## Description
For this homework, students will create a simple movie watchlist program using Python lists. The program will allow users to add movie titles to their watchlist, remove movies they have already watched, check whether a particular movie is already on the list, and see all the movies currently in their watchlist.

## Learning Outcomes
- Create a list in Python.
- Use .append() to add movie titles to a list.
- Use .remove() to remove movie titles from a list.
- Check whether a movie is already in the list.
- Print a list to display its contents.

## Homework Tasks
1. Create an empty list to store movie titles and ask the user to enter a movie to add using .append().
2. Allow the user to remove a movie from the watchlist using .remove().
3. Ask the user to enter a movie title and check whether it is already in the list.
4. Print the final watchlist so the user can see all the movies currently stored
